# Configuration map

- `../scaffoldseal/config_v2.yaml`: frozen version-2 study configuration.
- `../scaffoldseal/requirements.txt`: release-safe analysis requirements.
- `../requirements-reporting.txt`: reporting and figure requirements.
- `../requirements.txt`: combined pip entry point.
- `../environment.yml`: combined Conda entry point.
- `../docs/BASELINE_ENVIRONMENT.txt`: separate pinned upstream DMPNN reproduction environment and source commit.

The baseline and release-safe reporting environments are deliberately documented separately because they serve different parts of the workflow.
