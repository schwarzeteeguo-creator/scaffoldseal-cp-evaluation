# ScaffoldSeal-CP v0.7.5

## Release title

Submission-ready reproducibility package for *DMPNN Performance Estimates Diverge across Evaluation Boundaries in a Cyclic-Peptide Permeability Benchmark*.

## Release notes

This version contains the manuscript and Supporting Information, deterministic figure code, release-safe curation and split manifests, aggregate source data, reporting code, governance records and SHA-256 checksums. It records the official CycPeptMPDB download route and retains the non-redistribution boundary for upstream row-level structures and permeability labels because no separate redistribution licence was identified.

The package includes all artefacts needed to inspect the reported aggregate results and reconstruct release-safe curation outputs after an authorized user obtains the exact upstream file. It does not contain third-party row-level data, model weights, per-record predictions, residuals, caches or credentials.

The repository tag must remain immutable after release. Archive this exact GitHub Release with Zenodo, then add the minted DOI to the manuscript, `CITATION.cff` and the final release description.
